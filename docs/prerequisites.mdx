# Prerequisites

Before installing Smartposv7, ensure your system meets these requirements.

## Operating System

- **Windows 7** or newer version
- 64-bit operating system recommended

## Database Options

Smartposv7 supports two database options:

### Option 1: Microsoft SQL Server (Recommended for multi-user)
- **Version**: SQL Server 2016 or newer
- **Compatibility Level**: 2016 or higher must be set manually
- **Installation**: Must be installed **before** Smartposv7
- **Download**: [SQL Server from Microsoft](https://www.microsoft.com/en-us/sql-server/sql-server-downloads)

### Option 2: SQLite (Simple setup)
- **No installation required** - Embedded in application
- **Automatic setup** - Smartposv7 creates and manages database
- **Good for**: Single-user, testing, or small deployments
- **Limitation**: Single-user access only

> **Note**: Choose SQL Server for multi-user environments or SQLite for simple single-user setups.

## Qt Framework Compatibility

Smartposv7 is built on Qt framework with the following version requirements:

- **Minimum Supported Version**: Qt 6.4.3
- **Maximum Supported Version**: Qt 6.10
- **Note**: The Qt runtime is included with Smartposv7 installation - no separate Qt installation is needed.

## Application Modes

Smartposv7 operates in three UI modes. Ensure your hardware supports your intended use:

1. **Desktop Mode** (Default) - Standard monitor, keyboard, and mouse
2. **Kiosk Mode** - Touch screen recommended for self-checkout
3. **Mobile Mode** - Touch screen devices (Android/iOS support in future)

## Pre-Installation Checklist

### For SQL Server Setup:
- [ ] Windows 7 or newer operating system
- [ ] SQL Server 2016+ installed
- [ ] SQL Server compatibility level set to 2016 or higher
- [ ] SA password created and recorded

### For SQLite Setup:
- [ ] Windows 7 or newer operating system
- [ ] No additional database installation needed
