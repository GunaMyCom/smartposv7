# Second Display Settings

Go to **Settings → Second Display** to customize what customers see on the secondary screen.

![Second Display Settings](/assets/images/second_display.png)

*Above: Customer display configuration screen*

## 📺 Display Layout

Configure **split-screen** display:

### **Left/Upper Half: Advertisement**
- Promotional messages
- Product advertisements  
- Store information
- Social media links

### **Right/Lower Half: Billing Information**
- Running bill total
- Scanned items
- Discounts applied
- Payment status

## 🎨 Customization Options

- **Split Ratio**: Adjust ad/billing space (50/50, 40/60, etc.)
- **Ad Content**: Upload images/videos for ads
- **Text Size**: Adjust billing display text
- **Theme Colors**: Match store branding
