# SQL Server Manual Setup

Smartposv7 requires **manual setup** of SQL Server. The application does NOT configure SQL Server automatically.

## Step 1: Download SQL Server

1. Go to the official Microsoft website:
   **[Download SQL Server 2016 or newer](https://www.microsoft.com/en-us/sql-server/sql-server-downloads)**

2. Choose the appropriate edition:
   - **Developer Edition**: Free for development (recommended for testing)
   - **Express Edition**: Free for production (limited to 10GB database)
   - **Standard/Enterprise**: For commercial use

## Step 2: Install SQL Server

During SQL Server installation, you must configure:

### Critical Settings:
1. **Authentication Mode**: Select **Mixed Mode** (SQL Server and Windows Authentication)
2. **Set SA Password**: Create and remember a strong password for the 'sa' account
3. **Enable Features**: Ensure **Database Engine Services** is checked

### Installation Checklist:
- [ ] SQL Server 2016 or newer version
- [ ] Mixed Mode authentication enabled
- [ ] SA password set and recorded
- [ ] SQL Server service is running

## Step 3: Set Compatibility Level

**This step is manual and required:**

1. Open **SQL Server Management Studio (SSMS)**
   - Download SSMS: [https://aka.ms/ssmsfullsetup](https://aka.ms/ssmsfullsetup)

2. Connect to your SQL Server instance

3. Run this SQL command:
   ```sql
   -- Set compatibility level to 2016 (130) or higher
   ALTER DATABASE [master] SET COMPATIBILITY_LEVEL = 130;
