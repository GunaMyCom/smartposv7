<Steps>
  <Step title="Phase 1: Prerequisites" icon="check-circle">
    Ensure your system meets these requirements:
    
    1. **Windows 7 or newer** operating system
    2. **For SQL Server users only**: Download SQL Server 2016+ from Microsoft website
  </Step>
  
  <Step title="Phase 2: Installation" icon="download">
    Install Smartposv7 on your system:
    
    1. **Download library files** (.zip) and extract to `smartposv7/` folder
    2. **Download application** (.exe) and place in same `smartposv7/` folder
    3. **For global access** (recommended CLI method):
    
    ```cmd
    :: Set as Administrator
    setx SMARTPOSV7_LIB "C:\path\to\smartposv7\" /M
    setx PATH "%PATH%;%SMARTPOSV7_LIB%" /M
    ```
  </Step>
  
  <Step title="Phase 3: Initial Configuration" icon="settings">
    Configure the application settings:
    
    **Run Smartposv7.exe once** → Creates all config files automatically
    
    **Configure ServerSetup.sqlite:**
    ```ini
    ClientId=20130                      # Your company ID (MANDATORY)
    loc_id=001                          # Store location (MANDATORY)
    ServerType=RETAIL                   # Must be RETAIL (MANDATORY)
    DriverType=QSQLITE                  # QSQLITE or QODBC
    BackOfficeDownloadUrl=              # Can be empty (MANDATORY field)
    MasterDownloadFrom=cloud-erp        # cloud-erp, inv-1.8, or inv-v4 (MANDATORY)
    SalesUploadSink=cloud-erp           # cloud-erp, inv-1.8, or inv-v4 (MANDATORY)
    SalesUploadPort=8814/WEBCLOUD_TESTSRV/api/v1/opm/SalesUploadToOpm
    SalesUploadServerIP=https://web.mycomsys.com
    AutomaticalSalesSyncing=true        # true or false
    CoutrCloseDay=1
    CoutrCloseHour=1
    CoutrCloseMin=0
    ReportWidth=43
    ```
    
    **Configure MachineSetup.sqlite:**
    ```ini
    ClientId=21103                      # Your client code (MANDATORY)
    loc_id=001                          # MUST match ServerSetup value (MANDATORY)
    PosID=12                            # Terminal number (MANDATORY)
    Tax_Enable=true                     # Enable tax (MANDATORY)
    taxType=IN                          # IN (Inclusive) or EX (Exclusive) (MANDATORY)
    ApplicationType=RETAIL-POS          # RETAIL-POS or RESTPOS (MANDATORY)
    SubApplicationType=SMARTPOSV7       # SMARTPOSV7 or SMARTPOSV5 (MANDATORY)
    UIMode=RETAIL-POS                   # RETAIL-POS or RETAIL-SELF-CHECKOUT (MANDATORY)
    DownloadMasters=["group_master","item_master","price_mast","subgroup_master","tax_master"]
    ```
  </Step>
  
  <Step title="Phase 4: First Launch" icon="play">
    Start the application for the first time:
    
    1. **Launch application** (first time takes longer due to Windows security)
    2. **Check top-right status** → Must be GREEN (🟢)
    3. **Login** with default credentials:
       - Username: `demo`
       - Password: `demo`
  </Step>
  
  <Step title="Phase 5: Data Setup" icon="cloud-download">
    Download necessary product data:
    
    1. **Click Master Download** button from home screen
    2. **Choose source**: 
       - Back Office (complete download)
       - Cloud ERP (selective download)
    3. **Download** product, tax, and pricing data
    4. **Verify** data loaded successfully
  </Step>
  
  <Step title="Phase 6: Start Operations" icon="shopping-cart">
    Begin daily sales operations:
    
    1. **Open Shift** (REQUIRED before any sales)
       - Re-enter credentials
       - Add petty cash if needed
    2. **Click Billing** → Start first sale
    3. **Scan items** → Process payment → Print receipt
  </Step>
  
  <Step title="Phase 7: Daily Routine" icon="refresh-cw">
    Regular daily operations:
    
    1. **Open shift** each morning
    2. **Process sales** throughout day
    3. **Close shift** at end of day
    4. **EOD Sync** to upload sales data
  </Step>
</Steps>
