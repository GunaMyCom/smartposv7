# Installation Guide

Smartposv7 supports manual installation on Windows and Android platforms.

<Tabs>
<TabItem label="Windows Installation">

## Windows Installation

### Step 1: Download Library Files

1. Download the latest library package from:
   **[https://example.com/smartposv7-library.zip](https://example.com/smartposv7-library.zip)**

2. Extract the ZIP file to create the `smartposv7` directory
   ```plaintext
   Extracted structure:
   smartposv7/
   ├── Qt6Core.dll
   ├── Qt6Gui.dll
   ├── Qt6Widgets.dll
   ├── ... (all required .dll files)
   └── README.txt
   ```

> **⚠️ Important**: Do not delete or rename any files in this directory.

### Step 2: Download Application Executable

Download the latest Windows build:
**[https://example.com/smartposv7-latest.exe](https://example.com/smartposv7-latest.exe)**

### Step 3: Choose Installation Method

#### Method A: Local Directory (Simple)
1. Copy `smartposv7-latest.exe` into the `smartposv7/` directory
2. Run the application from this location
3. **No system configuration needed**

#### Method B: Global Access (Advanced)
For running the application from any location:

**GUI Configuration:**
1. Open System Properties → Advanced → Environment Variables
2. Add new System Variable:
   - **Variable name**: `SMARTPOSV7_LIB`
   - **Variable value**: `C:\path\to\smartposv7\`
3. Edit PATH variable → Add: `%SMARTPOSV7_LIB%`

**CLI Configuration (Command Prompt as Admin):**
```batch
:: Set library path environment variable
setx SMARTPOSV7_LIB "C:\path\to\smartposv7\" /M

:: Add to system PATH
setx PATH "%PATH%;%SMARTPOSV7_LIB%" /M
```

### Step 4: Verification
1. Open Command Prompt
2. Check environment variable:
   ```batch
   echo %SMARTPOSV7_LIB%
   ```
3. Run application from any location:
   ```batch
   smartposv7-latest.exe
   ```

## Android Installation

### Step 1: Download APK File

Download the Android APK from:
**[https://example.com/smartposv7-android.apk](https://example.com/smartposv7-android.apk)**

### Step 2: Install APK

1. On your Android device, go to **Settings → Security**
2. Enable **"Install from unknown sources"** or **"Allow from this source"**
3. Open the downloaded APK file
4. Tap **"Install"** and follow the prompts
5. Launch Smartposv7 from your app drawer

### Step 3: First-Time Setup

**Known Issue - First Launch Connection Problem:**
- On the **first launch only**, the application may fail to connect to the server
- **Solution**: 
  1. Close the application completely
  2. Reopen the application
  3. Connection should work normally

> This issue occurs only during the initial application mount and is resolved by restarting.

### Step 4: Verification
1. Check app appears in app drawer
2. Launch application
3. If connection fails → Close app → Reopen

## Common Issues & Solutions

<Tabs>
<TabItem label="Windows Issues">

### Windows Troubleshooting

| Issue | Solution |
|-------|----------|
| **"DLL not found" error** | Ensure all .dll files are in same directory as .exe |
| **Permission denied** | Run Command Prompt as Administrator |
| **Environment variable not working** | Restart Command Prompt after setting variables |
| **Application won't start** | Check Windows 7+ compatibility |

**GUI Method Fails?** Use CLI method with Admin rights.

</TabItem>
<TabItem label="Android Issues">

### Android Troubleshooting

| Issue | Solution |
|-------|----------|
| **"App not installed" error** | Enable "Unknown sources" in security settings |
| **Connection issues on first launch** | Close app completely and restart |
| **Storage permission required** | Grant storage access when prompted |
| **APK won't download** | Check internet connection and storage space |

**Connection still failing?** Clear app data and try again.

</TabItem>
