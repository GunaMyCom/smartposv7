# Initial Setup Guide

Welcome to Smartposv7! This guide will help you configure the application for the first time.

## 📁 Where Files Are Created

When you first run Smartposv7, it automatically creates necessary files:

```plaintext
Your Application Folder/
├── Smartposv7.exe           # Main application
├── settings.ini            # Tells app where to look for databases
├── MachineSetup.sqlite     # GUI and display settings (colors, layout)
├── ServerSetup.sqlite      # Server and connection settings
└── (other .sqlite files)   # For other features (we'll add later)
```

> **💡 Important**: All files are created in the **same folder** where `Smartposv7.exe` is located.

## ⚙️ How the Application Finds Database Files

The application reads `settings.ini` to know where to look:

```ini
# settings.ini content
[General]
appPath=C:/Users/YourName/Documents/Smartposv7/
```

**Translation**: "Look for my database files in this folder: `C:/Users/YourName/Documents/Smartposv7/`"

## 🏗️ Two Ways to Use Smartposv7

Smartposv7 works in two different setups. Choose **ONE**:

### **Option 1: Standalone Mode (Simple)**
![Master Download](/assets/images/single_pos.svg)
- **For**: One store, one computer
- **Server is INSIDE** the application
- **No extra installation** needed
- **Good for**: Small shops, testing

### **Option 2: Central Server Mode (Multiple POS)**
![Master Download](/assets/images/multi_pos.svg)
- **For**: Multiple stores or multiple checkout counters
- **Separate POS Server** installation needed
- **Multiple computers** connect to one server
- **Good for**: Supermarkets, chain stores

> **📥 Download POS Server**: [Download Pos Server](https://devp.mycomsys.com:8807/files/Smartpos7/SmartPosServer.exe)  
> (Same installation steps as Smartposv7)

## 🚀 Quick Start - Sample Sales Setup

Follow these steps to set up for your first sale:

1. **Run Smartposv7.exe** once (creates all files automatically)
2. **Edit ServerSetup.sqlite** with these minimum settings:
   - `ClientId` = `20130`
   - `loc_id` = `001`
   - `DriverType` = `QSQLITE`
   - `ServerType` = `RETAIL`
3. **Edit MachineSetup.sqlite** with these minimum settings:
   - `Tax_Enable` = `true`
   - `PosID` = `12`
   - `UIMode` = `RETAIL-POS`
4. **Restart Smartposv7**
5. **Start selling!**

## 🤔 Still Confused?

**Think of it like this:**
- **ServerSetup.sqlite** = "How to connect" (like Wi-Fi password + server addresses)
- **MachineSetup.sqlite** = "How to look" (like phone display settings + store setup)
- **Together** = Working POS system ready for sales
