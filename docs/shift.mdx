# Shift Management

**Shift Management** controls daily operations. You **must** open a shift before starting sales.

## 🔍 Shift Status Check

When you click **Shift** button, the system checks:

![Shift](/assets/images/shift.png)

## 🔓 Opening a New Shift

If no shift is running:

### Step 1: Authorization
- System prompts for **User ID and Password**
- Re-enter credentials for security
- Click **"Open Shift"** button

### Step 2: Shift Information
After authorization:
- Shift number is generated
- Start time is recorded
- User information is saved
- Shift status becomes **"Open"**

## 💰 Cash Management Options

Once shift is open, two options appear:

<Tabs groupId="cash-options">
<TabItem label="Petty Cash (Cash Float)" value="petty-cash">

### Add Starting Cash
**Purpose**: Put initial cash in drawer for giving change.

**Steps:**
1. Click **"Post Petty Cash"** button
2. Enter cash amount
3. Select denomination breakdown (optional)
4. Click **"Confirm"**

**Example:**
```
Total Petty Cash: ₹5,000
Breakdown:
- ₹2,000 × 1 note
- ₹500 × 4 notes  
- ₹100 × 10 notes
- ₹50 × 20 notes
```

**Best practice**: Add enough cash for daily change needs.

</TabItem>
<TabItem label="Cash Declaration" value="cash-declaration">

### Declare Cash Denominations
**Purpose**: Count and declare cash by denomination at shift start/end.

**Prerequisite**: Must setup **CashDeclaration Master** first.

**Steps:**
1. Click **"Cash Declaration"** button
2. System shows configured denominations
3. Enter counts for each denomination
4. System calculates total
5. Click **"Save Declaration"**

</TabItem>
</Tabs>

### How to Setup:
1. Go to **Settings → Masters → Cash Declaration**
2. Add each denomination with:
   - Coinage type (string): "1", "10", "100", etc.
   - Conversion factor (double): Same as denomination
   - Currency code (string): "AED" or "INR"
3. Save configuration

## 🔒 Shift Security Features

- **One shift per terminal** at a time
- **User authentication** required to open
- **Automatic time tracking**
- **Cash accountability**
- **Audit trail** of all actions

## 📊 Shift Reports

During shift, you can view:
- **Current shift sales**
- **Cash in drawer**
- **Transaction count**
- **Opening/Closing time**

## 🔚 Closing a Shift

To end daily operations:

1. Click **"Close Shift"** button
2. Perform **Cash Declaration** (count all cash)
3. Enter **Closing Cash Amount**
4. System calculates **Difference**
5. Confirm closure
6. Shift status becomes **"Closed"**

## ⚠️ Important Notes

1. **No billing possible** without open shift
2. **Shift must be closed** before EOD Sync
3. **One shift per day** per terminal
4. **Cash declaration** is mandatory at closure
5. **All data saved** for reporting
