# Smartposv7 Documentation

**Smartpos Version 7** - A modern retail Point of Sale system built with **Qt framework and C++**, designed for flexibility and performance in retail environments.

---

## 🎯 **Quick Overview**

Smartposv7 is a comprehensive retail POS solution that supports multiple interface modes for different use cases:

### **Three UI Modes**
1. **Desktop Mode** (Default) - Full-featured interface for staff operations
2. **Kiosk Mode** - Simplified self-checkout interface for customers  
3. **Mobile Mode** - Touch-optimized interface for mobile devices (Android/iOS in future)

- **Language**: C++
- **Database**: Microsoft SQL Server 2016+
- **Platform**: Windows 7 and above

---

## 🚀 **Getting Started Path**

Follow these steps in order:

1. **Check Prerequisites** → Verify system requirements
2. **Setup Database** → Install SQL Server 2016+
3. **Install Application** → Run Smartposv7 installer
4. **Configure UI Mode** → Choose Desktop/Kiosk/Mobile mode in Settings
5. **Begin Operations** → Start using the POS system

---

## 📋 **System Requirements Summary**

| Component | Minimum Requirement |
|-----------|---------------------|
| **Operating System** | Windows 7 or newer |
| **Database** | SQL Server 2016+ (Compatibility level 2016+) |
| **Qt Framework** | 6.4.3 to 6.10 (included) |
| **UI Modes** | Desktop (default), Kiosk, Mobile |

---

## 🔄 **Switching Between UI Modes**

All UI mode switching is done through the application's **Settings menu**:
- Navigate to: **Settings → UI Mode**
- Select your preferred mode (Desktop/Kiosk/Mobile)
- Application restarts automatically in selected mode
