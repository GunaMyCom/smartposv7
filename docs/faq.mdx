# UI Modes Configuration

Smartposv7 provides three distinct user interface modes, each optimized for specific retail scenarios. Switching between modes is done through application settings.

## Mode Comparison

| Feature | Desktop Mode | Kiosk Mode | Mobile Mode |
|---------|--------------|------------|-------------|
| **Primary Use** | Staff operations | Self-checkout | Mobile sales |
| **Interface** | Full-featured | Simplified | Compact |
| **Input** | Keyboard/Mouse | Touch screen | Touch screen |
| **Access Level** | Full admin | Limited public | Staff only |
| **Screen Layout** | Multi-window | Single screen | Responsive |
| **Printing** | Full control | Receipt only | Optional |

## Desktop Mode (Default)

### Overview
The **Desktop Mode** is the default and most feature-complete interface, designed for store staff and administrators.

### Key Features
- **Complete POS functionality**
- **Inventory management**
- **Reporting and analytics**
- **Employee management**
- **System configuration**
- **Multiple window support**

### Typical Use Cases
- Cashier operations
- Manager tasks
- Inventory management
- Reporting generation
- System administration
