# Printer Settings

Go to **Settings → Printer** to configure your receipt printers, invoice printers, and printing preferences.

![Printer Settings](/assets/images/printer-settings.png)

*Above: Printer configuration screen*

## 🖨️ What You Can Configure

- **Receipt Printer**: Thermal printer for customer receipts
- **Invoice Printer**: For detailed invoices and reports  
- **Printing Preferences**: Paper size, margins, logo
- **Test Print**: Verify printer setup

## 🔧 Basic Setup

1. Select printer type (Thermal/Network/Bluetooth)
2. Configure paper width (80mm/58mm/A4)
3. Set character per line
4. Test print to verify
