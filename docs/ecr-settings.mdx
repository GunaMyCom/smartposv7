# ECR Settings

Go to **Settings → ECR** to configure Electronic Cash Register hardware integration.

![ECR Settings](/assets/images/ecr.png)

*Above: ECR hardware configuration screen*

## 💰 ECR Provider Configuration

Select your ECR provider and configure:

### **Supported Providers:**
- **Provider A**: Serial port configuration
- **Provider B**: USB integration  
- **Provider C**: Network ECR setup
- **Provider D**: Bluetooth connection

## ⚙️ Hardware Settings

Based on selected provider:

- **Connection Type**: Serial/USB/Network/Bluetooth
- **Port Configuration**: COM port, baud rate
- **Device ID**: ECR identification
- **Test Connection**: Verify hardware communication

## 🔌 Common Features

- Cash drawer control
- Payment terminal integration  
- Receipt printing
- Transaction logging
