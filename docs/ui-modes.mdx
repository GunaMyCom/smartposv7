# UI Mode Configuration Guide

Smartposv7 supports multiple UI modes for different retail scenarios. Each mode requires specific settings in **two configuration files**.

## 📋 Configuration Files Overview

| File | Purpose | Location |
|------|---------|----------|
| **MachineSetup.sqlite** | Controls **interface appearance** and **user experience** | Same folder as Smartposv7.exe |
| **ServerSetup.sqlite** | Controls **server type** and **backend behavior** | Same folder as Smartposv7.exe |

## 🎯 How to Change UI Mode

To switch between UI modes, you must **update both files**:

1. **Open** `MachineSetup.sqlite` → Set `ApplicationType`, `SubApplicationType`, `UIMode`
2. **Open** `ServerSetup.sqlite` → Set `ServerType`
3. **Restart** Smartposv7 application

### Restaurant POS System
For sit-down restaurants with waiter service.

**📁 MachineSetup.sqlite Settings:**
```ini
ApplicationType = RESTPOS
SubApplicationType = (Not needed - leave empty)
UIMode = RESTPOS
```

**🖥️ ServerSetup.sqlite Settings:**
```ini
ServerType = RESTPOS
```

```ini
ServerType = RESTPOS
```


## 🔄 Switching Between Modes

**Important**: Always restart Smartposv7 after changing UI mode settings.

1. **Close** Smartposv7 completely
2. **Edit** both configuration files
3. **Save** changes
4. **Restart** Smartposv7
5. **Verify** new UI mode is active

## ❓ Common Questions

**Q: Can I switch modes without reinstalling?**  
A: Yes! Just edit the two configuration files and restart.

**Q: Which mode should I choose?**  
A: 
- **RESTPOS**: Restaurants with waiters
- **RETAIL-POS**: Retail stores with staff
- **SELF-CHECKOUT**: Customer-operated systems

**Q: What about mobile/tablet mode?**  
A: Mobile mode is **automatic** when running on mobile devices. No setup needed.

**Q: Do I need different ServerSetup for each mode?**  
A: Only `ServerType` changes:
- `RESTPOS` for restaurant modes
- `RETAIL` for retail modes
