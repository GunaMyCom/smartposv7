# Voice Settings

Go to **Settings → Voice** to enable/disable voice announcements for different events.

![Voice Settings](/assets/images/voice_settings.png)

*Above: Voice announcement configuration screen*

## 🔊 Voice Events

Toggle voice announcements for:

- **Sale Complete**: "Thank you for your purchase"
- **Payment Received**: "Payment successful"  
- **Item Scanned**: Item name announcement
- **Error Alerts**: "Please try again"
- **Welcome Message**: When customer approaches

## ⚙️ Configuration

- **Volume Control**: Adjust announcement volume
- **Language**: Select announcement language
- **Event Selection**: Choose which events trigger voice
- **Test Voice**: Preview announcements

*Voice settings help create audible feedback for transactions.*
