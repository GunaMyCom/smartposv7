# Home Screen Overview

Welcome to Smartposv7 Home Screen! This is your main dashboard with 6 key functions:

![Home Screen Layout](/assets/images/home_screen.png)

## 🎯 Navigation Buttons

| Button | Purpose | Next Action |
|--------|---------|-------------|
| **[Billing →](/billing)** | Start customer transactions | Scan items → Create bill |
| **[Shift →](/shift)** | Manage daily shift operations | Open/Close shift → Cash handling |
| **[Reports →](/reports)** | View sales and inventory reports | Select report type → Generate |
| **[Settings →](/settings)** | Configure application preferences | Adjust settings → Save changes |
| **[Master Download →](/master-download)** | Download product and tax data | Choose source → Download masters |
| **[EOD Sync →](/eod-sync)** | End-of-day data synchronization | Sync sales → Upload to server |

## 🔄 Recommended Workflow

For **first-time setup**, follow this order:

1. **Master Download** → Get product data
2. **Shift** → Open daily shift
3. **Billing** → Start sales
4. **Reports** → Check sales data
5. **Shift** → Close shift
6. **EOD Sync** → End day data sync
